# Первооткрыватели — Online MVP 0.20.0

Сетевой мобильный прототип настольной игры «Первооткрыватели». Версия 0.17 подготовлена для облачного запуска на Render и установки как PWA на Android. Игровая часть наследует 0.16, которая закрывает обязательные последствия потери мест верфи и обновляет особую награду Ландина по текущей авторской редакции: Ландин занимает одно из максимум трёх мест сопровождения, совмещает боевой эскорт (+6 артиллерии) и торговый эскорт (отдельный трюм 5), а при уже заполненном пределе заменяет одно выбранное владельцем судно.

## Версия 0.20.0: сохранение партий и «Мои игры»

- Таблица `game_rooms(code TEXT PRIMARY KEY, state JSONB, updated_at TIMESTAMPTZ)` создаётся автоматически в существующей базе аккаунтов.
- Полный снимок сохраняется после изменений лобби, ходов, решений и подключений. Сохраняются колоды, скрытые карты, порядок ходов и незавершённые решения. Клиент получает только положенную ему публичную часть.
- Сохранения и удаления упорядочены; подтверждение действия отправляется после записи. При временной ошибке записи повторяются, новые действия блокируются до восстановления сохранения. SIGTERM дожидается записи, не разрешая незавершённые решения за отключаемых игроков.
- Перед приёмом соединений сервер восстанавливает незавершённые комнаты: `socketId=null`, `connected=false`. Ошибка подключения или некорректное сохранение останавливает запуск вместо открытия пустого сервера.
- Закрытие комнаты хозяином или администратором удаляет запись. Переход на стартовый экран и отключение сохраняют место игрока.
- `GET /api/my-games` с Bearer-токеном и Socket-событие `listMyRooms { accountToken }` возвращают комнаты только для accountId из проверенного токена. Переданный клиентом accountId не используется.
- `resumeRoom { code, accountToken }` возвращает место аккаунта без локального playerToken. Старое подключение этого игрока теряет управление, админ-наблюдение остаётся отдельным.
- PWA-кэш обновлён; `/api/*` и `/health` не кэшируются. `/health.roomPersistence` показывает число восстановленных комнат, очередь записи и состояние сохранения.

Проверки: `npm run check` и `npm test`. Интеграционные тесты запускают настоящий HTTP/Socket-сервер с тестовым эмулятором Postgres, принудительно завершают процесс и проверяют восстановление, приватность списка, возврат с другого устройства, наблюдение и удаление комнаты. Производственное окружение использует обычный драйвер `pg`.

Развёртывание рассчитано на один экземпляр игрового сервера. Горизонтальное масштабирование потребует координации состояния между процессами. Партии, существовавшие только в памяти версии 0.19, нельзя восстановить задним числом.

## Облачный запуск и Android

В корне проекта есть `render.yaml`: Render может развернуть этот проект как Node.js Web Service без ручной настройки порта. Сервер слушает `0.0.0.0` и использует переменную окружения `PORT`; `/health` служит HTTP health-check.

Клиент теперь является устанавливаемым PWA: добавлены manifest, service worker и иконки. После публикации по HTTPS Android/Chrome может установить игру на главный экран. Кнопка «Поделиться ссылкой» создаёт приглашение с `?room=КОД`, поэтому код комнаты у друга заполняется автоматически. Подробная пошаговая инструкция находится в `DEPLOY-ANDROID.md`.

При настроенном `DATABASE_URL` комнаты сохраняются в Postgres и восстанавливаются перед запуском сервера. Без базы доступен прежний гостевой режим с хранением только в памяти.

- автоматическая потеря той части итогового строительного приза, которую невозможно разместить.

## Общая Фаза событий

После завершения пятого полного круга обычные личные ходы приостанавливаются. Сначала фиксируются политические статусы, активные поручения и вражда на начало фазы и взимаются налоги Лионии/Кадингира. Затем в постоянном порядке игроков каждый получает по одной карте события плавания. После событий сервер проходит зафиксированный список вражд и выдаёт карты вражды в порядке Лиония → Кадингир → Майо → Суниксия → пираты. Затем вассалы, у которых не было активного поручения на начало фазы и которые всё ещё остаются вассалами, получают новое поручение. Последняя стадия даёт каждому действующему вассалу возможность один раз оставить поручение или заменить его за 2 дуката. После этого начинается следующий раунд, снимаются отметки погрузки и посещённых морских якорей.

Эффекты «ближайший личный ход» хранятся отдельно и переносятся в активные эффекты при начале следующего личного хода. «Удача Фортуны» бросает два d6 и использует лучший; попутный ветер и штиль меняют максимум движения; «Поломка» сразу переводит игрока к трём действиям без обычной навигации; «Голод» отменяет только доход рынков и банков этого хода. Добровольный отказ от навигации не переносит временный эффект дальше.

Сохранённые карты найденного груза и полного трюма руды можно применить позднее за одно действие в любой пустой активный трюм. «Судовой мастер» устанавливает одно улучшение бесплатно, но только в допустимом месте и при наличии места/предыдущего улучшения ветви. Чертежи строят соответствующее здание бесплатно, сохраняя площадь и остальные требования строительства.

Важно: правила указывают, что случайная легендарная колода состоит из 8 карт четырёх видов, но в документе не указано количество каждого вида. В MVP 0.17 временно используется симметричный состав по две карты каждого вида. Эта композиционная договорённость вынесена в `game-data.js` для простой замены; сами четыре эффекта уже реализованы.

## Государства, подданство и вражда

Политический модуль использует пять фракций, для которых правила задают карточки отношений и колоды вражды: Лиония, Кадингир, Майо, Вольная Суниксия и пираты. Сёгунат Мори остаётся государственным владельцем своих островов на карте, но в текущей редакции правил для него не приведены отдельные отношения/колода вражды, поэтому он пока не включён в эту подсистему.

Вступить в подданство можно только к Лионии, Кадингиру, Суниксии или пиратам. Игрок должен находиться на клетке острова соответствующей фракции, государство должно продолжать существовать, а передаваемый остров должен всё ещё принадлежать государству. После принятия подданства сервер сразу передаёт Франдию / Кадингир / Суниксию / Чертонию соответственно. Майо подданства не имеет.

Мятеж доступен в фазе действий и стоит одно действие. Если подаренный остров всё ещё принадлежит вассалу, он возвращается государству вместе с постройками; активное поручение сразу сбрасывается, а бывший вассал становится врагом сюзерена. Нападение вассала на собственного сюзерена вызывает этот же мятеж автоматически непосредственно перед атакой.

Вражда создаётся в момент объявления нападения на государство, его остров или корабль/остров вассала, а также соответствующими «Пламенем Ада» и «Морским проклятием». Защита союзника сама по себе вражды не создаёт. Когда государство прекращает существование, его вражда удаляется у всех игроков и новые карты этой колоды больше не выдаются.

В начале общей Фазы событий вассалы Лионии и Кадингира платят по 2 дуката из текущей казны. Недостающая часть не превращается в долг; вместо этого ближайший личный ход ограничивается двумя действиями. После событий плавания каждый игрок получает по одной карте вражды от каждой зафиксированной на начало фазы враждебной фракции. Для неоднозначных эффектов правил — например, какой из нескольких подходящих островов Лиония возвращает или какую постройку понизить — MVP оставляет выбор затронутому игроку через интерфейс, а не выбирает цель скрыто.

Поручения сюзерена и итоговые призы полного подчинения реализованы. Итоговый приз может быть получен только один раз за партию для каждой политической фракции и только в момент успешного военного захвата, после которого один игрок контролирует все её исходные острова.

Если последний остров сохранён, выдаются готовые здания: Лиония — два Рынка I; Кадингир — Банк I и Рынок I; Майо — Рынок I; Суниксия и пираты — по два Рынка I. Они размещаются немедленно на любом своём острове без требования фермы, защитного здания и присутствия корабля, но с обычной проверкой площади и предела ветви 2/3/4. Если очередное здание нигде не помещается, эта часть приза автоматически пропадает.

Если последний остров разорён, вместо зданий начисляется итоговый денежный приз: Лиония 60, Кадингир 48, Майо 4, Суниксия 12, пираты 12 дукатов. Для финального разорения денежная награда карточки последнего острова не складывается с итоговым денежным призом; это следует явно указанному в правилах примеру Кадингира «48 всего, а не 48 + 36». При одновременном получении одинаковых призовых зданий острова и государства совпадающие экземпляры не дублируются: например, при сохранении Кадингира Банк I выдаётся один раз, а итоговый Рынок I остаётся для размещения.

## Поручения сюзерена

В игре четыре колоды поручений: Лиония — 10 карт, Кадингир — 10, пираты — 9, Вольная Суниксия — 10. Майо подданства не имеет. Сервер хранит порядок карт скрыто и показывает игроку только его собственное активное поручение.

Поручение фиксирует момент выдачи. Захват острова засчитывается только военным штурмом после выдачи; строительство и улучшение — только действием после выдачи; уровень и корабельные улучшения, посещение легендарных мест, победа на нужном якоре и получение сокровища отслеживаются тем же способом. Для доставки груз должен быть получен после выдачи именно текущего экземпляра поручения, затем физически доставлен и продан в Цитадели.

Для поручений доставки никакой отдельной контрактной премии нет. Подходящий полный трюм продаётся в Цитадели по обычной цене, после чего начисляется отдельная награда поручения. Пираты и Вольная Суниксия удерживают половину только этой награды поручения. Все денежные поступления проходят через общую механику долга.

Один раз за общую Фазу событий действующий вассал с активным поручением и минимум 2 дукатами получает выбор: оставить карту или заменить её. Условие платно заменённой карты записывается за игроком до конца партии, поэтому то же условие нельзя заменить за плату повторно. Невыполнимые карты при выдаче пропускаются базовой проверкой состояния игры.

Активное поручение не блокирует добровольные действия игрока. Сервер по-прежнему определяет, можно ли выполнить поручение прямо сейчас на текущей позиции имеющимися средствами и действиями, но публикует это только как подсказку владельцу. Игрок вправе выбрать другое действие или завершить ход. Если к концу общего раунда поручение остаётся активным, с игрока один раз за этот раунд взыскивается 1 дукат; казна не уходит ниже нуля, долг не создаётся, поручение остаётся активным.

## Исправление острова после потери статуса

Если разрушение, понижение здания, карта события, карта вражды или «бунт владений» меняют статус острова, сервер заново считает доступную площадь и предел каждой из шести обычных ветвей. Поселение допускает максимум 2 постройки одной ветви, город — 3, крупный порт — 4. Бонус площади города и крупного порта также пересчитывается сразу.

Если после этого здания больше не помещаются либо какая-то ветвь превышает новый предел, появляется обязательная панель «Исправление острова». Владелец удаляет по одной выбранной постройке без возврата дукатов. После каждого удаления статус, площадь и пределы рассчитываются заново; игра продолжается только когда одновременно выполнены оба ограничения.

Эта проверка работает и во время общей Фазы событий: выдача следующих карт приостанавливается до исправления острова, затем продолжается с того же места. При потере статуса крупного порта постоянный гарнизон автоматически становится городской стражей; при потере статуса города городской отряд распускается.

## Легендарные карты

Карты из случайной легендарной колоды и одноразовые «Покров моря» / «Путь сквозь туман», полученные другими правилами, отображаются в одной панели. Обычное применение происходит в свою фазу действий и стоит одно действие.

«Покров моря» можно направить на собственную флотилию или любой собственный остров. Если карта сыграна в свой ход, текущий ход не входит в три следующих. При объявлении атаки или «Пламени Ада» владелец цели получает отдельное окно реакции. Если он применяет «Покров моря», объявленный эффект отменяется, но действие нападающего уже списано.

«Пламя Ада» требует находиться на клетке чужого острова. Каждая постройка выше I уровня понижается на одну ступень; постройки I уровня остаются без изменений. Активный «Покров моря» не позволяет применить эффект к цели. Если цель принадлежит государству или его вассалу, эффект создаёт соответствующую вражду; применение против собственного сюзерена предварительно вызывает автоматический мятеж.

«Путь сквозь туман» использует ту же цифровую разметку препятствий, что обычная навигация, но не ограничен броском d6. После выбора карты все допустимые клетки подсвечиваются на поле; перенос расходует одно действие, после него оставшиеся действия текущего хода сохраняются. Остановка после такого переноса может дать свободный остров по общему правилу, но не разыгрывает морской якорь как обычную навигацию.

«Морское проклятие» применяется к чужому основному кораблю на той же клетке. В первом раунде и зоне мира Цитадели оно запрещено. Каждый активный эффект даёт −3 к обычной дальности движения на три следующих личных хода цели; несколько эффектов технически складываются. Уже действующий «Покров моря» отменяет карту.

## Морские якоря

Если игрок завершает навигацию на клетке якоря, сервер сразу проверяет, посещал ли он эту конкретную клетку в текущем раунде. Если нет, открывается верхняя карта соответствующей колоды.

Синие якоря находятся на клетках `5,11`, `9,1`, `16,5`, `22,11`; жёлтые — `5,25`, `10,16`, `18,21`; красный — `26,21` (координаты в коде 0-indexed: строка, столбец). Эти координаты соответствуют символам на приложенной карте 28×28.

Для обычной морской карты сравнивается артиллерия флотилии игрока с артиллерией карты. При победе игрок получает указанную награду и славу по цвету якоря. При поражении уровень корабля не снижается: вместо этого взимается денежный штраф. Если денег не хватает для обязательного минимума, остаток становится долгом. При равенстве силы игрок получает пропуск следующего личного хода. Карта «На море тихо» только фиксирует посещение якоря и не расходует действие.

Порядок карт колод не передаётся клиенту. Интерфейс показывает только количество карт в колоде и сбросе и уже открытый результат столкновения.

## Союзы и совместный бой

Чтобы заключить союз, основные корабли двух игроков должны находиться на одной клетке. В свой ход инициатор открывает панель «Союзы» и отправляет предложение. Второй игрок принимает или отклоняет его на своём телефоне. Если союз принят, у инициатора списывается одно действие; при отказе действие не тратится.

Разорвать действующий союз можно бесплатно только в начале своего личного хода, до навигации. В этот же ход игрок не может атаковать бывшего союзника.

При объявлении боя инициатор может позвать союзников. Для морского боя союзник должен находиться на клетке корабля-цели; для штурма — на любой клетке того же острова. Подходящие союзники защиты тоже получают приглашение. Каждый отвечает «участвовать» или «не участвовать», после чего сервер автоматически разрешает бой.

В совместном морском бою складывается артиллерия основных кораблей и активного боевого сопровождения всех участников стороны. В совместном штурме складывается войско основных кораблей атакующих; сопровождение в штурме не участвует.

## Морской бой

Чтобы атаковать корабль другого игрока, обе флотилии должны стоять на одной клетке. В фазе действий откройте панель «Бои» и нажмите «Атаковать».

Сервер сравнивает артиллерию основного корабля с активными улучшениями и активное боевое сопровождение. Кубик в бою не бросается. Атака расходует одно действие и сама по себе не завершает личный ход.

При победе проигравший теряет один общий уровень, а победитель забирает из его казны не более 3 дукатов. Если проигравший уже на I уровне, его корабль возвращается на стартовую клетку. Если уменьшение уровня сократило основной трюм, лишний груз сбрасывается.

При равенстве силы каждый участник обеих сторон получает отметку пропуска следующего личного хода. Сервер пропускает такой ход автоматически и не начисляет доход за пропущенный ход.

## Штурм острова

Основной корабль атакующего должен находиться на клетке выбранного острова. В панели «Бои» отображается текущая сила защиты.

Для захвата доступны две кнопки:

- `Сохранить · одному` / `Сохранить · союз` — остров переходит инициатору вместе с существующей инфраструктурой; положенные наградные здания добавляются;
- `Разорить · одному` / `Разорить · союз` — все здания острова удаляются, после чего остров переходит инициатору. Денежные одноразовые награды карточки острова сохраняют действие.

Для острова без владельца используется его исходный гарнизон. После перехода острова игроку исходный гарнизон больше не добавляется к защите. Если корабль владельца находится на любой клетке своего острова, его войско добавляется к защите.

## Разовые военные награды

В 0.17 реализованы денежные награды карточек островов и наградные здания, которые уже могут быть представлены существующей моделью построек. Крепость I и Банк I добавлены как наградные продвинутые здания; они пока не доступны для обычной покупки/улучшения игроком.

Случайные легендарные карты Асигория, Адии и Черепа вытягиваются в закрытую руку и теперь могут быть непосредственно применены через панель «Легендарные карты».

## Авторская редакция Ландина в 0.17

В исходном документе награда Ландина описана как особое боевое сопровождение. В этой сборке применено более новое уточнение автора игры: особое судно Ландина одновременно считается боевым и торговым по характеристикам (+6 артиллерии, трюм 5), не требует места верфи, но входит в общий предел максимум трёх судов сопровождения. При полном пределе оно обязательно заменяет одно выбранное существующее судно.

## Что пока не реализовано полностью

- полный набор правил крупных портов и все продвинутые формы строительства;
- при потере мощности поддержки каменотёсных дворов активные бастионы выбираются по сохранённому приоритету; изменить приоритет можно бесплатно в свой ход;
- отдельная механика контрактов отсутствует; все задания государства являются поручениями сюзерена, а доставочные поручения не дают дополнительного бонуса к цене продажи;
- постоянные сохранения партий в базе данных.

## Разметка карты

Клетки берегов, препятствий и якорей находятся в `game-data.js`. Они откалиброваны по приложенной карте 28×28. Клетки Цитадели задаются в `CITADEL_CELLS`; зона мира вычисляется из этих клеток и соседних морских клеток. Якоря задаются в `ANCHORS`, состав морских колод — в `ANCHOR_CARDS`.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm test
npm start
```

После запуска откройте `http://localhost:3000`.

### Игра с телефонов в одной Wi‑Fi сети

Запустите сервер на компьютере, узнайте его локальный IP, например `192.168.1.25`, и откройте на телефонах `http://192.168.1.25:3000`. Фаервол должен разрешать входящие подключения на порт 3000.

### Публикация в интернете

Это обычное Node.js-приложение с Socket.IO. Хостинг должен поддерживать Node.js и WebSocket. Команда запуска — `npm start`, порт берётся из переменной `PORT`.

Автоматические тесты проверяют навигацию, строительство, торговлю, развитие флота, ручной выбор отключаемых улучшений/сопровождения после потери уровня, сохранение груза на неактивном эскорте, зону мира, одиночные и совместные бои, союзы, морские якоря, события и легендарные карты, а также политическую модель: состав пяти колод вражды, вступление в подданство, передачу острова, мятеж, исчезновение государства, снятие вражды, все 39 поручений, полное подчинение государств, недублирование приза Кадингира и размещение итоговых призовых зданий, а также роты ландскнехтов, поддержку бастионов и городские гарнизоны.

## Ограничение MVP

С `DATABASE_URL` незавершённые комнаты и партии восстанавливаются из Postgres после перезапуска. Без базы комнаты хранятся только в памяти.
