# Как запустить «Первооткрыватели Online» без Termux

Эта версия подготовлена для Render. После публикации все игроки открывают обычную HTTPS-ссылку в Chrome. Никакой Node.js на телефонах не нужен.

## Самый короткий путь

1. Создайте бесплатный аккаунт GitHub и загрузите содержимое этой папки в новый репозиторий.
2. Откройте Render и войдите в аккаунт.
3. Нажмите **New → Blueprint**.
4. Подключите GitHub и выберите репозиторий с игрой.
5. Render автоматически прочитает `render.yaml`. Подтвердите создание сервиса.
6. Дождитесь статуса **Live**. Render выдаст адрес вида `https://pervootkryvateli-online-....onrender.com`.
7. Откройте ссылку на Android, создайте комнату и нажмите **Поделиться ссылкой**. Другу останется ввести имя и выбрать корабль.

## Установка на главный экран Android

После открытия HTTPS-ссылки Chrome может показать кнопку **Установить на телефон** прямо в игре. Если кнопки нет, используйте меню Chrome → **Добавить на главный экран** / **Установить приложение**.

## Что важно знать о бесплатном Render

Комнаты сейчас хранятся в оперативной памяти сервера. Пока игроки активно обмениваются WebSocket-сообщениями, бесплатный сервис остаётся активным, но перезапуск/новый деплой сервера удалит текущие комнаты. Для тестовых партий этого достаточно; для надёжных долгих сохранений следующим этапом нужна база данных.
